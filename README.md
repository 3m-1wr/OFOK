# OFOK — موقع حجز عيادات الأسنان

موقع حجز دكاترة أسنان (على طريقة فيزيتا) بدون أي مكتبات خارجية.

## التشغيل
1. نزّلي Node.js (الإصدار 22.13 أو أحدث) من nodejs.org وأعيدي فتح الـ terminal.
2. افتحي الفولدر في الـ terminal واكتبي:

```
node server.js
```
3. افتحي http://localhost:3000

(لو البورت مشغول: `set PORT=3100 && node server.js` على ويندوز.)

## حسابات تجريبية (كلمة السر 123456)
- مدير: admin@demo.com
- مريض: patient@demo.com
- دكاترة: doctor1@demo.com … doctor8@demo.com

## الأدوار
- **المريض**: يسجّل بنفسه، يتصفح الدكاترة والخدمات، يحجز على خدمة معينة، يتابع حجوزاته ويقيّم، وتبويب "تواصل معنا".
- **الدكتور**: يشوف حجوزاته وتقييماته ويختار الخدمات اللي بيقدمها (تبويب خدماتي). التسجيل للدكتور من الأدمن فقط.
- **الأدمن**: لوحة تعرض الأعلى تقييماً وربحاً وأكثر الخدمات حجزاً، وإدارة الدكاترة (السعر، المواعيد، العنوان، الخدمات)، وإدارة الخدمات (إضافة/تعديل/حذف/إيقاف)، وروابط التواصل الاجتماعي.

## الخدمات
12 قسم و74 خدمة جاهزة (الأقسام 1–5 مقترحة والباقي حسب قائمتك). كلها قابلة للتعديل من الأدمن → الخدمات. الخدمة المرتبطة بحجوزات بتتوقف (مش بتتحذف) للحفاظ على السجلات.

## تعديلات سريعة
- روابط فيسبوك/إنستجرام/لينكد إن: الأدمن → روابط التواصل.
- صورة خلفية الدخول: استبدلي `public/bg.jpg`.
- اللوجو: `public/logo.png`.
- قاعدة البيانات `ofok.db` بتتعمل تلقائياً، ولو موجودة من نسخة قديمة بتتحدّث لوحدها. امسحيها لو عايزة تبدأي من الصفر.

بعد التحديث اعملي Ctrl+F5 عشان المتصفح يحمّل الملفات الجديدة.
